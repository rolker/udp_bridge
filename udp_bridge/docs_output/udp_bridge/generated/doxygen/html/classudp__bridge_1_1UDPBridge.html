Detailed Description

The top level class containing all the functionality of the udp_bridge_node. Once the constructor has read initial parameters and created the network socket, the spin method then sets up the services and reads the initial remote connections and topics from the parameter server before going into a loop to read incoming UDP packets and decode them.

Meanwhile, the callback method handles sending ROS messages from locally subscribed topics to remote nodes.

Additional timer callbacks are used to locally publish and send to remotes information about the local bridge (udp_bridge::UDPBridge::bridgeInfoCallback) and data statistics (udp_bridge::UDPBridge::statsReportCallback).
