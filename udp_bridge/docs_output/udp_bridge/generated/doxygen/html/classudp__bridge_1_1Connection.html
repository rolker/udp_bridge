Detailed Description

Represents a connection to a remote node. Multiple connections to a remote node may be used for redundancy.

◆ data_receive_rate()

std::pair< double, double > udp_bridge::Connection::data_receive_rate ( double  time)

Returns the average received data rate at the specified time. The first element of the returned pair is for unique bytes/second and the second element is for duplicated bytes per second. Duplicated bytes are for packets that had already been received on another connection.
