# Bridging Robots over unreliable neworks with udp_bridge

The udp_bridge package was developed for use with surface marine robots comminicating with operators over unreliable networks.
It allows the selection of topics to forward and to rate limit them. Data is compressed and bandiwth limits are used to keep from saturating connections.

Multiple data paths can be used for redundancy allowing seemless operation using wifi, mesh radios, cellular links, or satelite internet.
